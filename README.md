# 代码库

按日期整理的编程练习代码 + 蓝桥杯竞赛训练代码，用 Visual Studio 编写，
同时推送到 Gitee 与 GitHub 两个远端。

## 目录结构

| 目录 | 内容 |
|---|---|
| `练习测试代码/` | 日常练习 —— 172 个按日期命名的独立 VS 工程（C 语言基础、C++、数据结构、手写 STL 容器） |
| `竞赛代码/` | 蓝桥杯竞赛训练代码 |

- 每个工程目录是一个独立的 VS 项目（`.sln` + `.vcxproj` + 源文件），
  目录名就是当天的日期，例如 `test_9.10`、`2026_3.10`、`2026_11.3`
- `练习测试代码/README.md` 里有这一分区的单独说明
- 编译产物（`.vs/`、`Debug/`、`Release/`、`x64/`、`*.ipch`、`*.pdb`、`*.obj`、
  `*.tlog` 等）不纳入版本管理，规则见根目录 `.gitignore`
